## 🚀 Ishga Tushirish Bo‘yicha Ko‘rsatma

Sayt hech qanday Node.js, server yoki kutubxona o‘rnatishni talab qilmaydi.

### 1-usul: Oddiy ochish
1. `META-IT-SCHOOL` papkasini oching.
2. `index.html` faylini istalgan brauzerda (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari) ikki marta bosib oching.

### 2-usul: VS Code Live Server orqali (Tavsiya etiladi)
1. VS Code dasturida `META-IT-SCHOOL` papkasini oching.
2. `index.html` faylini o‘ng tugma bilan bosing va **"Open with Live Server"** buyrug‘ini tanlang.
3. Sayt brauzerda `http://127.0.0.1:5500/` manzili ostida ochiladi.
